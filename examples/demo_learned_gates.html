🏗️ Gate Generation Architecture

1. Task Embedder: LSTM encoder processes K example sequences → task embedding (64D)

2. Gate Generator: MLP takes task embedding → generates gate configuration

3. Three Heads:

  • write_gate_head: (num_channels × feature_dim) matrix
  • update_head: (num_channels × feature_dim) matrix
  • decay_head: (num_channels,) vector bounded [0.9, 0.99]
